# Showcase Pack

**The four cinematic flagships, shipped as a separate add-on.**

These are the demonstration-grade builds: the biggest, most spectacular skills in the catalogue, each carrying its full working engine inline. They install as an add-on zip handed out deliberately (a workshop, a client engagement, a premium tier); the standard Crew install excludes this pack on purpose so the everyday picker stays lean.

| Skill | Does | Output |
|---|---|---|
| `crew-web-learning-experience` | Activates a finished training programme into a presented learning journey: calm editorial steps on a block spine, plain openers, presenter-paced with a phone remote, editable in place, covering the whole guide | One self-contained journey `.html` |
| `crew-web-webcam-website` | Builds a webcam hand-tracking site where an AI subject follows the open palm and closing the fist scrubs a generated transformation video frame by frame, reversibly | One self-contained hand-tracking `.html` experience |
| `crew-web-immersive-narrative` | Builds a multi-stage gated story site: themed stages reveal on scroll, frame-scrubbed video advances frame-for-frame, a two-state gate paces the story, an arrival hero resolves each stage | One immersive narrative site |
| `crew-web-spotlight-hero` | Builds a dark full-screen hero where the cursor drags a soft glowing circle that reveals a second transformed image through a CSS radial-gradient mask | A React + Vite spotlight-reveal hero |

## Installing

Unzip `crew-showcase` into your skills folder exactly like any other pack, or run the bundled installer with `--pack showcase`. The pack is self-contained: every skill carries the full Crew harness, and if the business is not onboarded yet, the first run walks through onboarding inline.

The zip also bundles the two reviewer skills (`crew-design-quality`, `crew-design-engineering`) so the design review gate works even without the Design Standards pack; if they are already installed, the copies are identical and nothing changes.

## Why these four are separate

Each of these skills carries its complete engine in the skill body, which makes them the heaviest files in the catalogue. Keeping them out of the standard install keeps every other session light; installing this pack is a deliberate choice by someone who wants the flagship builds.
