# Core Crew Skills

**The safe way every job starts, runs, and ships.**

Every Crew begins here. These skills keep work clear, checked, and recoverable, no matter what the business does. The other packs hand off to these.

| Skill | Does | Output |
|---|---|---|
| `crew-core-using-crew` | Routes a task to the right Crew skill before it is answered from scratch | A dispatch decision (which skill, why) |
| `crew-core-idea-pressure-tester` | Pressure-tests a new idea before any work starts | Pressure-test summary plus a proceed, pause or reframe signal |
| `crew-core-plan-reviewer` | Reviews a plan before work begins (scope, approach, feasibility) | Plan review with risks, gaps, and recommendations |
| `crew-core-quality-checker` | Checks completed work against the brief before it ships | Quality report with issues, severity, and fixes |
| `crew-core-context-save` | Saves the state of work so it can be resumed cleanly | Handoff note with status, decisions, remaining work |
| `crew-core-context-restore` | Restores the last saved context to pick up where work stopped | Restoration summary with status and next actions |
| `crew-core-guard-boundary` | Sets a soft edit boundary so work stays in agreed scope | Boundary record, noted as a soft convention |

Install this pack: `./install.sh --pack core`
